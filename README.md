# HAI WiFi Guard

تطبيق Android دفاعي لفحص حماية شبكة Wi‑Fi التي يتصل بها جهازك حاليًا.

## ما الذي يفعله؟
- يعرض اسم الشبكة ونوع التشفير المتاح من Android.
- يحاول قراءة قدرات نقطة الوصول الحالية من نتائج Wi‑Fi المسموح بها للنظام.
- ينبه عند ظهور WPS في قدرات نقطة الوصول.
- يحدد عنوان الراوتر (Default Gateway) وعنوان الجهاز وDNS.
- يفحص وجود واجهة إدارة الراوتر محليًا على منافذ شائعة فقط، بدون استغلال أو تخمين كلمات مرور.
- يوفر اختبار قوة كلمة مرور محليًا بالكامل؛ النص لا يُحفظ ولا يُرسل.
- يعطي توصيات حماية عملية: WPA3/WPA2-AES، تعطيل WPS، تحديث Firmware، وتغيير كلمة مرور الإدارة.

## حدود مقصودة
هذا المشروع لا يحتوي على deauthentication أو WPS PIN brute force أو التقاط handshakes/PMKID أو كسر كلمات المرور أو صفحات Evil Twin. الهدف هو تقييم شبكتك والدفاع عنها.

## البناء
افتح المشروع في Android Studio (JDK 17). كما يوجد GitHub Actions workflow يبني Debug APK تلقائيًا عند كل push.
